# Music Downloader 当前结构

## 用户入口

### 导入
- Spotify 浏览器导入：内嵌 Spotify 页面，用户可登录自己的普通 Spotify 账号并打开专辑、播放列表、单曲或艺人页。
- 链接导入：粘贴 Spotify 专辑、播放列表、单曲或艺人链接后读取曲目元数据。
- 导入结果：展示曲库名称、类型、曲目数量、封面、歌名和艺人。
- 加入全部：把当前导入的全部曲目加入下载队列。

### 下载
- 下载队列按状态分组：正在下载、排队中、已完成、失败/取消。
- 每个任务展示曲名、艺人或候选来源、进度、状态和错误信息。
- 支持暂停、继续、重试、取消。
- 下载任务会在后台自动匹配公开 YouTube 音源，不需要用户确认候选结果。

### 设置
- 软件会员：默认试用版，VIP 激活码为可选项，普通用户无需填写。
- Spotify 普通账号提示：提醒用户在导入页登录自己的 Spotify 账号。
- 高级 Spotify API 配置：Client ID / Client Secret / API 连接，普通用户无需填写；用于完整分页导入和后续产品化封装。
- 下载设置：输出格式、音质偏好、同时下载数量、下载目录。

## 后台能力

- Spotify 元数据导入：优先读取官方 API，公开页面/公开元数据作为兼容回退。
- 长歌单处理：公开元数据疑似只返回 100 首时，不再当作完整成功；改为要求官方分页导入。
- 自动匹配音源：下载任务内部使用 `yt-dlp` 查询公开 YouTube 音源，并根据标题、艺人、时长、语言、官方/翻唱/现场等信号打分。
- 下载执行：`yt-dlp` + `ffmpeg` 负责下载、转码、断点续传、封面和元数据写入。
- 状态持久化：下载队列会保存到本机应用数据目录，重启后继续处理未完成任务。

## 当前已移除

- 歌名、歌手、专辑关键词搜索入口。
- 搜索结果/候选结果页面。
- 用户手动选择候选音源后再加入队列的交互。
- 前端公开搜索 IPC 与 Spotify/iTunes 目录搜索代码。

## 当前限制

- Spotify 不作为音频来源，只读取元数据。
- 不绕过 DRM，不复制 Spotify 或 Apple Music 原始音频。
- 未连接官方 Spotify API 时，部分很长的公开播放列表可能只能读到公开元数据源暴露的前 100 首；此时应用会提示需要完整授权，而不是把 100 首当成完整结果。
